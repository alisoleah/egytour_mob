# Egytour Mobile App

This repository contains the native mobile applications for Egytour, an app designed to help users explore the wonders of Egypt. The project is divided into two native sub-projects: one for iOS (using Swift and SwiftUI) and one for Android (using Kotlin and Jetpack Compose).

## Project Structure

The repository is organized into the following directories:

-   `docs/`: Contains the HTML design files that serve as a reference for the app's user interface and experience.
-   `assets/`: This directory is used for storing the initial image assets. The images are then copied into the platform-specific asset directories.
-   `ios/`: The Xcode project for the iOS application.
-   `android/`: The Gradle project for the Android application.

## Getting Started

To get started with development, you'll need to have the appropriate tools installed for either iOS or Android development.

### iOS

1.  Open the `ios/Egytour.xcodeproj` file in Xcode.
2.  Build and run the project on a simulator or a physical device.

### Android

1.  Open the `android/` directory in Android Studio.
2.  Let Gradle sync and build the project.
3.  Run the app on an emulator or a physical device.
